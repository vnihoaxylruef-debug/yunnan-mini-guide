# 雲南ミニガイド販売セット

このリポジトリは、雲南旅行向けの小さなデジタル商品を低コストで販売するための雛形です。

## 何が入っているか
- ランディングページ（index.html）
- 商品ガイドの原稿（guide-final.md）
- 商品説明文（sales-copy.txt）
- カバー画像のSVGサンプル（cover.svg）

## すぐやること
1. Gumroad にアカウントを作成する
2. guide-final.md を PDF に変換して、photos.zip を作る
3. Gumroad で Digital Product を新規作成する
4. フォルダをアップロードして価格を設定する
5. 商品URLを取得する
6. index.html の BUY_LINK をそのURLに置き換える
7. GitHub Pages でサイト公開する
8. 自分でテスト購入して自動ダウンロードが動くか確認する

## 便利なファイル
- guide-final.md: PDF 化の元になる本体原稿
- sales-copy.txt: Gumroad の説明文やSNS文が入っている
- cover.svg: 商品画像のテンプレート

## 価格の目安
- 最初は ¥800〜¥1,500 程度でテストするのがおすすめ
- 反応が良ければ ¥1,500〜¥2,500 に調整

## 公開手順
GitHub のリポジトリで次を実行
- Settings → Pages
- Source: Deploy from a branch
- Branch: main / root
- Save

数分後に公開URLが発行されます。

## 画像の準備
- cover.svg を使って、Gumroad のカバー画像として利用できます
- もしもっと本格的な画像が必要なら、Canva や Photoshop で置き換えてください

## 注意
- Gumroad のアカウントや銀行情報はここでは扱いません
- ここに入っている URL はダミーです。販売URLに置き換えてください

## 次の一手
- guide-final.md を PDF 化する
- 写真のZIPを作る
- Gumroad の商品ページを作る
- index.html の BUY_LINK を置き換える
- GitHub Pages を公開する

これで販売開始です。
